research
adaptive RL for dynamic ROI selection in rPPG
2025 – 2026
M.S. Thesis · SF State
  • Remote photoplethysmography (rPPG) extracts heart rate from video by detecting subtle color changes in facial skin caused by blood flow. The challenge is that different facial regions carry different signal quality depending on lighting, motion, and skin tone, and most methods fix the ROI at the full face or a static subregion. My thesis asks whether a PPO-trained agent can learn to dynamically select which facial regions to weight based on the current video context.
  • The state space is a 64-column semantic ROI12 schema derived from MediaPipe, 12 facial regions each with quality features. The action space is a continuous (12,) vector of region scores mapped to a top-k weighted ROI mixture (k=3 default). The policy selects among three signal extraction algorithms (POS, CHROM, PBV) dynamically based on the selected ROI. I trained on 3,600 videos across MMPD, V4V, and PURE datasets using SLURM-managed jobs tracked in W&B.
  • The best result is HR_MAE of 21.76 vs a baseline of 33.58, a meaningful improvement. But the honest tension is that HR_MAE gains come at a cost to PPG waveform correlation, and the policy behaves differently on frontal vs side-facing video in ways that aren't yet fully understood. The dense+sparse hybrid reward underperformed the sparse-only reward, which suggests the waveform-level signal is harder to translate into useful gradient than expected. That asymmetry is the most interesting open question in the thesis.

PivotRL — distillation via NLL pivot detection
ongoing 2026
personal research
ongoing
  • Hypothesis — not all tokens in a reasoning trace are equally worth learning from; NLL-based pivot detection identifies navigational transition points in Kimi K2.5 traces and applies higher loss weight to them when distilling into Gemma 4.
  • Results — uniform SFT hurt GSM8K performance (85.5% → 74.5%); pivot-weighted SFT partially recovered it to 80%, suggesting the pivot signal is real but the pipeline is incomplete.
  • Next step — running 50-sample AIME eval to test whether the regression is domain-specific; if pivot-weighted holds on AIME, the GSM8K drop reframes as distribution shift, not capability loss.
  • Honest status — ongoing, null-ish result so far, but the null is informative: naive distillation on reasoning traces actively hurts, which isn't obvious from the literature.
